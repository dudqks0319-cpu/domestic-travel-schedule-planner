# TripMate 정부지원사업 포지셔닝 초안

## 과제명 후보

공공데이터 기반 국내 여행 안전·로컬정보 일정 추천 서비스

## 핵심 문제

국내 여행 앱은 지도, 후기, 예약 기능은 강하지만 여행자가 일정 생성 시 확인해야 하는 날씨, 대기질, 공영주차장, 응급·약국, 관광 공공정보가 여러 채널에 흩어져 있다. 초행 여행자와 외국인 관광객은 일정 동선과 안전 정보를 함께 판단하기 어렵다.

## 해결 방향

TripMate는 TourAPI, 기상/대기질, 공영주차장, 응급의료·약국 등 공공데이터를 여행 일정 맥락에 결합한다. 사용자는 로그인 없이 목적지를 고르고, 기본 날짜가 자동 추천된 상태에서 관광지와 맛집을 선택해 시연용 일정을 만들 수 있다.

## 차별성

- 민간 후기 중심 서비스가 아니라 공공데이터 기반 안전·현지 정보 큐레이션에 초점
- 국내 여행지 특화 데이터 구조로 지역 관광 분산과 초행자 편의성 강화
- API 미연결 상태에서도 데모 데이터와 실서버 연결 상태를 분리해 베타 검증 가능
- 향후 다국어 안내, 응급 정보, 지역 축제, 소상공인 관광 상품 연계로 확장 가능

## 평가 포인트

- 공공데이터 활용성: 기상, 미세먼지, 공영주차장, 관광정보를 일정 생성 UX에 결합
- 관광 안전성: 날씨·대기질·응급 정보 기반의 여행 전 체크 강화
- 지역경제 기여: 국내 관광지와 지역 맛집 탐색, 향후 지역 소상공인 제휴 가능
- 실증 가능성: TestFlight/베타 앱으로 사용자 흐름과 데이터 카드 반응 검증 가능

## 이번 패치 범위에서 반영된 항목

- K-skill 공공 API 기반 날씨/미세먼지/주차 정보 카드
- 실서버 연결됨과 데모 데이터 사용 중 상태 분리
- 로그인 없는 게스트 사용 흐름
- 기본 날짜 자동 추천
- 4단계 게스트 일정 생성

## 추가 개발 과제

- 응급의료·약국 API 서버 프록시 연결
- TourAPI 관광지 응답 품질 개선과 이미지 캐싱
- 일정 편집, 공유, 오프라인 저장
- 외국인 관광객용 다국어 번역과 접근성 안내
- 지역 축제·행사 및 소상공인 혜택 연동
